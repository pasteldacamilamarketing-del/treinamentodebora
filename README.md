# Treinamento Debora — Pastel da Camila

Aplicação web estática e responsiva, pronta para GitHub Pages. Inclui banner corporativo principal da Home.

## Estrutura
- `index.html` — aplicação
- `assets/brand/` — logos e favicons
- `assets/home/` — imagens ativas da Home
- `assets/reference/` — artes guardadas como referência, não exibidas
- `docs/` — arquitetura e histórico

## Publicação
Envie todo o conteúdo desta pasta para a raiz do repositório.
GitHub → Settings → Pages → Deploy from a branch → `main` → `/(root)`.
